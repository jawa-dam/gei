# @gei/shared

Universal language and core value types for the GEI platform.

## Purpose

This package defines the shared vocabulary used across the repository.

## Contents

- Primitive types
- Identifiers
- Metadata models
- Version types
- State and lifecycle names
- Time and diagnostics helpers

## Rules

- No business logic
- No services
- No runtime behavior
- No dependencies on higher packages

Starter package
