# @gei/dependency-graph

Dependency modeling and resolution for GEI.

## Purpose

This package models graph relationships for services, manifests, and platform boot order.

## Rules

- Uses graph algorithms from `@gei/core`
- Uses shared types from `@gei/shared`
- Uses public contracts from `@gei/contracts`
- No UI
- No business logic outside graph responsibility
